# Docs / 补充文档索引

根目录 `01` 到 `06` 是主流程文档。本目录放更详细的产品、数据、接口、前端、后端、测试和部署 review 说明。

建议按下面顺序补充：

1. `01-product/`: 产品细节、用户故事、验收标准和产品决策。
2. `02-database/`: 数据模型、字段和约束。
3. `03-api/`: 前后端接口约定。
4. `04-frontend/`: 前端页面、组件、状态和交互规则。
5. `05-backend/`: 后端接口、业务规则和服务边界。
6. `06-testing/`: 测试计划、验证步骤和测试结果。
7. `07-deploy-review/`: 部署、预览链接、review 环境和检查方式。

不是每个项目都需要填满所有目录。只要项目涉及对应内容，就要把 reviewer 需要知道的信息写清楚。
