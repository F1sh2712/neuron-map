# 01 Product Docs / 产品文档

这里放产品相关补充文档。根目录 `02-prd.md` 是主文档，本目录用于补充用户故事、产品决策、验收标准和开放问题。

## 建议内容

- 用户故事
- 关键业务流程
- 详细验收标准
- 产品决策记录
- 暂未确定的问题

## PRD 最低标准

每个功能至少说明：

- 问题
- 用户
- 使用场景
- 功能范围
- 不做什么
- 用户流程
- 数据需求
- API 需求
- 验收标准
- 开放问题

## Acceptance Criteria / 验收标准

验收标准要具体，可以被验证。

弱标准：

- 页面好用。
- 功能完成。

强标准：

- 用户可以创建一条 student record。
- 缺少 required field 时显示错误。
- 创建成功后列表中能看到新记录。
- 刷新页面后数据仍然存在。
