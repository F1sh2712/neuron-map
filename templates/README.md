# Templates / 可复制模板索引

这些模板用于减少学生从空白文档开始写的成本。可以复制到根目录主文档、`docs/` 子目录、PR description 或周进度记录中。

1. `01-prd-template.md`: PRD 模板。
2. `02-api-spec-template.md`: API 文档模板。
3. `03-test-plan-template.md`: 测试计划模板。
4. `04-ai-usage-log-template.md`: 单次 AI 使用记录模板。
5. `05-weekly-progress-template.md`: 周进度汇报模板。

复制后要替换示例内容，不要只保留空表格。
