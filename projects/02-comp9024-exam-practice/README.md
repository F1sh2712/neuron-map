# COMP9024 期末题型练习网站

## 项目定位

这个项目面向正在学习 COMP9024 或类似数据结构与算法课程的学生，目标是做一个期末复习练习网站，覆盖选择题、填空题和简答题。

重点不是复刻真实考试题库，而是帮助学生围绕核心知识点进行结构化练习、即时反馈和错题复盘。

## 目标用户

- 准备 COMP9024 期末考试的学生
- 需要复习数据结构、算法复杂度、图、树、排序、哈希等知识点的学生
- 导师或助教，用来组织练习题和讲解错题

## 核心问题

期末复习时常见的问题是：

- 知识点很多，但学生不知道自己薄弱在哪里
- 选择题和填空题缺少即时反馈
- 简答题很难自查是否答到关键点
- 错题没有沉淀，复习容易重复低效

本项目希望把练习、反馈、错题和知识点复盘连接起来。

## MVP 功能范围

第一版建议只做这些功能：

- 题库列表：按知识点、题型、难度筛选
- 选择题练习：单选或多选，提交后显示正确答案和解析
- 填空题练习：支持关键字或精确答案匹配
- 简答题练习：学生填写答案后展示参考要点
- 错题本：记录答错或标记不熟的题目
- 练习统计：显示各知识点完成数量和正确率
- 题目管理数据：可以先用 JSON、Markdown 或本地数据库维护

## 可选扩展

在 MVP 跑通后，可以选择继续扩展：

- 随机组卷
- 限时模拟考试
- 知识点掌握雷达图
- 简答题 AI 初步评分或关键词覆盖检查
- 学生复习计划推荐
- 导师端新增、编辑、导入题目
- 每道题关联复习资料链接

## 不做什么

第一版不建议做：

- 收集或传播真实未公开考试题
- 做完整商业考试系统
- 复杂监考、防作弊或浏览器锁定
- 复杂权限和班级管理
- 对简答题做完全自动化高风险评分

## 推荐交付物

学生选择这个项目后，至少需要交付：

- 可运行的网站或本地 Web app
- 至少 30 道示例题，其中包含选择题、填空题和简答题
- 每道题标注知识点和难度
- 每道选择题或填空题有答案和解析
- 简答题有参考要点，而不是只给一句答案
- 错题本或复习记录功能
- README 或 `03-runbook.md`，说明如何运行
- `04-ai-usage.md`，记录 AI 如何辅助生成题目、解释或代码

## 验收标准

导师 review 时可以重点看：

- 学生能否按知识点选择练习
- 不同题型是否都有完整答题流程
- 答题后是否能看到反馈和解析
- 错题是否能被记录并重新练习
- 统计是否能帮助学生发现薄弱知识点
- 题目内容是否为自编、公开或教学示例，避免侵权或泄露

## 适合的学生

适合想练习以下能力的学生：

- 前端表单和交互设计
- 题库数据建模
- 学习产品的信息架构
- 简单统计和可视化
- AI 辅助教学工具设计

## 导师沟通问题

开始前建议先和导师确认：

- 题目是否需要完全自编
- 是否允许参考公开资料总结知识点
- 第一版是否要支持登录和个人错题本
- 简答题反馈应做到什么程度
- 练习模式优先做按知识点练习，还是模拟考试
