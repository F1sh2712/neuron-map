# 课程评价社区

## 项目定位

这个项目面向学生选课和课程复盘场景，目标是做一个轻量课程评价社区，让学生可以浏览课程评价、提交学习体验、比较课程难度，并为后续选课提供参考。

第一版重点是可信、清晰、可 moderation 的评价流程，而不是做成大型社交平台。

## 目标用户

- 正在选课、想了解课程真实体验的学生
- 上完课后愿意分享学习建议的学生
- 导师或项目负责人，用来了解学生对课程和学习支持的反馈

## 核心问题

学生选课时常见的问题是：

- 课程官方介绍偏抽象，缺少真实学习体验
- 难度、 workload、评分方式和前置知识不透明
- 不同学生背景差异大，评价很难直接比较
- 评价容易变成情绪表达，缺少结构化信息

本项目希望让课程评价更结构化、更可比较，也更适合作为后续课程改进的反馈来源。

## MVP 功能范围

第一版建议只做这些功能：

- 课程列表：展示课程代码、课程名、学院或方向
- 课程详情：展示评分汇总、评价列表和常见标签
- 发布评价：学生填写评分、学习投入、难度、收获和建议
- 结构化评分：例如难度、workload、实用性、教学清晰度
- 标签系统：例如编程多、数学多、项目重、考试难、适合新手
- 搜索和筛选：按课程代码、关键词、评分或标签查找
- 基础审核状态：评价可以有 pending、published、rejected 状态

## 可选扩展

在 MVP 跑通后，可以选择继续扩展：

- 匿名评价
- 评价点赞或有用标记
- 按学生背景过滤评价，例如编程基础强弱
- 课程对比功能
- 课程时间线，展示不同学期评价变化
- 管理员审核后台
- 不当内容举报
- AI 总结课程优缺点，但必须能追溯到原始评价

## 不做什么

第一版不建议做：

- 公开真实学生隐私信息
- 攻击性或诽谤性内容传播
- 复杂社交关系、私信或关注系统
- 课程官方评分替代品
- 未审核的敏感评价直接公开

## 推荐交付物

学生选择这个项目后，至少需要交付：

- 可运行的网站或本地 Web app
- 至少 8-10 门示例课程
- 至少 20 条明显为虚构的示例评价
- 课程列表、课程详情、发布评价、筛选搜索流程
- 基础内容审核字段或审核页面
- README 或 `03-runbook.md`，说明如何运行
- `04-ai-usage.md`，记录 AI 如何辅助设计评价维度、生成假数据或开发代码

## 验收标准

导师 review 时可以重点看：

- 课程评价是否结构化，而不是只有自由文本
- 用户是否能快速判断一门课的难度和适合人群
- 搜索、筛选和课程详情是否可用
- 示例数据是否明确为 fake data
- 是否考虑隐私、审核和不当内容处理
- 是否避免真实学生个人信息和敏感评价外泄

## 适合的学生

适合想练习以下能力的学生：

- 社区类产品设计
- 前后端 CRUD
- 搜索、筛选和排序
- 评价数据建模
- 内容审核和隐私边界设计

## 导师沟通问题

开始前建议先和导师确认：

- 评价是否必须匿名
- 是否需要管理员审核后才能发布
- 示例课程和评价是否全部使用虚构数据
- 评分维度应该有哪些
- 第一版更重视课程浏览，还是评价发布和审核流程
