# COMP9021 Python 刷题训练系统

## 项目定位

这个项目面向正在学习 COMP9021 或类似 Python 编程课程的学生，目标是做一个轻量版的在线刷题系统，帮助学生练习 Python 基础、算法思维和代码调试能力。

可以参考 LeetCode、Ed 练习题、课堂 lab 的体验，但本项目不需要一开始做成完整平台。优先做一个可运行、可演示、可扩展的最小系统。

## 目标用户

- 正在学习 Python 基础和数据结构的学生
- 需要通过练习题巩固语法、循环、函数、递归、文件处理、简单算法的学生
- 导师或助教，用来布置练习题、查看提交结果和讲解常见错误

## 核心问题

学生刷题时常见的问题是：

- 不知道该按什么难度顺序练习
- 写完代码后缺少即时反馈
- 不容易复盘错误原因
- 练习题、测试数据、参考思路分散在不同地方

本项目希望把题目、代码提交、运行结果、测试反馈和学习记录放在一个统一系统里。

## MVP 功能范围

第一版建议只做这些功能：

- 题目列表：展示题目标题、难度、标签和完成状态
- 题目详情：展示题目描述、输入输出说明、样例和限制条件
- 代码编辑区：学生可以输入 Python 代码
- 运行代码：支持使用公开样例运行代码并展示输出
- 提交代码：使用预设测试用例判断通过或失败
- 提交记录：保存每次提交时间、代码、运行结果和错误信息
- 简单后台数据：题目和测试用例可以先用 JSON、Markdown 或本地数据库维护

## 可选扩展

在 MVP 跑通后，可以选择继续扩展：

- 难度分级和推荐下一题
- 题目标签筛选，例如 list、dict、recursion、sorting、string
- 隐藏测试用例
- 错误类型分类，例如语法错误、运行错误、答案错误、超时
- 代码运行沙箱
- AI 代码提示，但不能直接给完整答案
- 导师端题目管理
- 学生排行榜或练习 streak

## 不做什么

第一版不建议做：

- 完整 LeetCode 级别的平台架构
- 复杂多人实时协作
- 付费题库内容搬运
- 真实课程考试题原题库
- 复杂权限系统
- 大规模代码评测集群

## 推荐交付物

学生选择这个项目后，至少需要交付：

- 可运行的网站或本地 Web app
- 至少 8-12 道示例题
- 每道题至少 3 个测试用例
- README 或 `03-runbook.md`，说明如何运行
- 简单 `02-prd.md`，说明用户流程和功能边界
- 截图或录屏，证明题目、运行、提交、记录功能可用
- `04-ai-usage.md`，记录 AI 如何辅助开发

## 验收标准

导师 review 时可以重点看：

- 学生能否打开题目并写代码
- 样例运行是否能返回输出
- 提交后是否能判断通过或失败
- 错误信息是否对学习有帮助
- 题目数据和测试数据是否结构清晰
- 项目是否避免泄露真实课程题库或学生数据

## 适合的学生

适合想练习以下能力的学生：

- Python 后端或全栈开发
- 在线代码运行和结果展示
- 基础数据建模
- 产品化学习工具设计
- 自动化测试和边界条件设计

## 导师沟通问题

开始前建议先和导师确认：

- 是否允许使用 COMP9021 风格的自编题，而不是课程原题
- 第一版是否需要在线运行 Python，还是可以先做本地模拟评测
- 是否需要学生账号系统
- 题目数量和难度范围如何控制
- AI 提示功能是否允许出现，边界是什么
